## 3. Инциденты и Дрифт 

### 📉 Пример деградации модели (Model Decay)
**Ситуация:** Модель была обучена на летних видео (яркое освещение).
**Симптом:** Зимой пользователи загружают видео с искусственным освещением. Confidence модели YOLO падает с 0.9 до 0.6.
**Решение:** Дообучение на новом датасете с низким освещением.

### 🌪 Пример дрифта данных (Data Drift)
**Ситуация:** Входной формат видео изменился с 1080p на 4K.
**Симптом:** Резко выросло время обработки, так как размер тензора увеличился в 4 раза.
**Детекция:** Мониторинг метрики `input_tensor_shape` или `processing_time`.
